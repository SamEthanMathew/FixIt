HOW TO SOLVE THIS - READ CAREFULLY
You have two sources of evidence: the NUMBERS in the geometry block, and the SIMULATOR. Use both,
and trust the simulator over your own inference.

READ THE NUMBERS FIRST. The geometry block gives every part's size along X, Y and Z.
  - A SIZE fault shows up directly: compare the faulty candidate's size vector against the other
    door's. The axis whose ratio is furthest from 1 is the axis to correct, and that ratio is
    roughly the SCALE factor you need. Two doors on the same cabinet are normally close in size.
  - A POSITION fault shows up as a centre offset on one axis while the sizes match.
  These readings are a good starting hypothesis. They are NOT proof - confirm with a probe.

THEN USE THE SIMULATOR AS A MEASURING INSTRUMENT. Every action is applied FRESH to the original
broken object - attempts never stack - so each SIMULATE is an independent, repeatable experiment,
and a bad probe costs you nothing but the turn.

Let E be the error in millimetres reported for the current object, and let e = E / 1000 (the same
distance in metres). Then:

  STEP 0 - the probe size is ALWAYS computed from E, or from a ratio you read off the geometry
     block. Never reuse a number from the examples above; they are formatting illustrations and
     have nothing to do with your object.

  STEP A - FIND THE FAULTY PART FIRST. Probe each targetable part once and watch the error:
       - the number CHANGES (up OR down)  -> this part is the faulty one. A healthy part cannot
         change how wrong the faulty part is, so any movement at all identifies it.
       - the number is EXACTLY the same as before -> this part is healthy. Stop probing it.
     An error that goes UP still identifies the right part. Once known, use it in EVERY later probe.

  STEP 1 - probe translation. Try  TRANSLATE(part, X, -e).
     - error drops to near zero  -> that was the fault. COMMIT this action.
     - error roughly DOUBLES     -> right axis, wrong sign. Try TRANSLATE(part, X, +e).
     - error barely changes      -> the fault is not a translation along X. Move on.
  STEP 2 - repeat STEP 1 for Y, then for Z.
  STEP 3 - if no translation helped, the fault is a rotation or a size error. Probe
     ROTATE(part, A, 20) for each axis A, and SCALE(part, A, f) using the ratio you read from the
     geometry block. A large drop in the error means you found the right operation and axis.

  STEP 4 - LOCK ON. The moment any probe cuts the error by half or more, the search is OVER: you
     have found the operation, the part and the axis. STOP EXPLORING. Every remaining turn must
     reuse that same operation, part and axis and change ONLY the value. Going back to probing
     other combinations after a big drop throws the episode away.
     To pick the next value: if value V took the error from A down to B, then V closed (A - B) of
     the gap, so the value that closes all of A is about V * A / (A - B). For a SCALE, if factor f
     left the part still too large, the next factor is smaller than f, and vice versa.

Never repeat a probe you have already run - it will return the identical result and waste a turn.
