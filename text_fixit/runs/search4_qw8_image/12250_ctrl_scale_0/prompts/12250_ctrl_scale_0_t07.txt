HOW TO SOLVE THIS - READ CAREFULLY
Do NOT try to judge from the pictures which axis is wrong. That judgement is unreliable at this
image size, and a wrong guess wastes the whole episode. **Use the simulator as your measuring
instrument instead.** Every action is applied FRESH to the original broken object - attempts never
stack - so each SIMULATE is an independent, repeatable experiment, and a bad probe costs you nothing
but the turn.

Let E be the error in millimetres reported for the current object, and let e = E / 1000 (the same
distance in metres). Then:

  STEP 0 - the probe size is ALWAYS computed from E. Never reuse a number from the examples above;
     they are formatting illustrations and have nothing to do with your object.

  STEP A - FIND THE FAULTY PART FIRST. If the turn prompt already marks a part CONFIRMED FAULTY,
     that part is settled by probe evidence - skip this step entirely and target only that part.
     Targeting a ruled-out part is rejected outright and wastes the turn. Do this before hunting for the operation or the axis.
     Probe each targetable part once and watch the reported error:
       - the number CHANGES (up OR down)  -> this part is the faulty one. A healthy part cannot
         change how wrong the faulty part is, so any movement at all identifies it.
       - the number is EXACTLY the same as before -> this part is healthy. Stop probing it entirely.
     An error that goes UP still identifies the right part. Do not abandon a part because your
     first probe made things worse - that only means the direction or the operation was wrong.
     Once the faulty part is known, use it in EVERY later probe.

  STEP 1 - probe translation. Try  TRANSLATE(part, X, -e).
     - error drops to near zero  -> that was the fault. COMMIT this action.
     - error roughly DOUBLES     -> right axis, wrong sign. Try TRANSLATE(part, X, +e).
     - error barely changes      -> the fault is not a translation along X. Move on.
  STEP 2 - repeat STEP 1 for Y, then for Z.
  STEP 3 - if no translation helped, the fault is a rotation or a size error. Probe
     ROTATE(part, A, 20) for each axis A you have not ruled out, and SCALE(part, A, 0.8).
     Again: a large drop in the error means you found the right operation and axis.
  STEP 4 - LOCK ON. The moment any probe cuts the error by half or more, the search is OVER: you
     have found the operation, the part and the axis. STOP EXPLORING. Every remaining turn must
     reuse that same operation, part and axis and change ONLY the value. Going back to probing
     other combinations after a big drop throws the episode away - this is the most costly mistake
     available to you.
     To pick the next value: if value V took the error from A down to B, then V closed (A - B) of
     the gap, so the value that closes all of A is about V * A / (A - B). For a SCALE, if factor f
     left the part still too large, the next factor is smaller than f, and vice versa.

  WRONG PART? If two DIFFERENT probes leave the error EXACTLY unchanged, you are not acting on the
     faulty part at all - moving a healthy part cannot change how wrong the faulty one is. When that
     happens, stop probing that part and switch to another id from the targetable list. Check this
     first: it is the cheapest mistake to detect and the most expensive to ignore.

  SIZE ERRORS: a size fault can lie on any axis, so probe SCALE on X, Y and Z before ruling size out.
     Do not settle for the axis you tried first.
